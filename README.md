# Sohaybah Bux Physiotherapy Website

A professional, responsive healthcare website designed and developed from scratch for **Sohaybah Bux Physiotherapy**, a physiotherapy practice based in Ballito, KwaZulu-Natal, South Africa.

## 🌐 Live Website

**[Visit the Live Website](https://sohaybahbuxphysio.co.za/)**

---

## 📋 About the Project

This project was created to provide Sohaybah Bux Physiotherapy with a modern, professional online presence that reflects the practice's approach to personalised patient care.

The website was designed with a focus on clean layouts, approachable healthcare branding, accessibility, responsive behaviour and a simple user journey from discovering the practice to booking an appointment.

## ✨ Features

* Responsive design for desktop, tablet and mobile devices
* Custom healthcare-focused visual design
* Custom colour palette and typography
* Responsive navigation with mobile menu
* Physiotherapy services overview
* Detailed areas of care
* Appointment booking integration with Calendly
* Click-to-call phone links
* Click-to-email functionality
* Instagram integration
* Custom favicon
* SEO-friendly page titles and descriptions
* Canonical URLs
* `robots.txt`
* XML sitemap
* Mobile-specific responsive styling
* Custom fonts and branded graphics

## 📱 Responsive Design

The website was built to provide a consistent experience across different screen sizes.

Responsive layouts were implemented for:

* Desktop
* Laptop
* Tablet
* Mobile

Particular attention was given to mobile navigation, typography, spacing, card layouts and preventing horizontal overflow on smaller screens.
